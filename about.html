CYBERGUARD SECURITY LAB

A safe place to learn security.

CyberGuard Test Server is a controlled web application created to demonstrate how application activity can be captured, monitored and investigated by a security operations environment.

🧪
PURPOSE

Testing & education

The application provides a small, controlled environment where authentication and test activity can be generated without interacting with a production application.

📡
EVENT PIPELINE

Activity becomes telemetry

Relevant application activity is recorded as security events in Supabase. CyberGuard SOC can then use those events for monitoring, detection and investigation.

🛡️
MONITORING

Connected to CyberGuard SOC

The Test Server acts as the application being monitored, while the separate SOC provides the analyst-facing environment for examining security activity.

🔒
BOUNDARIES

Not a production system

This environment is intentionally limited. It should never receive real credentials, personal information or sensitive institutional data.

SYSTEM FLOW

How the environment works

⚠
IMPORTANT

Use this environment responsibly.

This application is built for cybersecurity education, controlled demonstrations and academic testing. Do not use real passwords, personal credentials, confidential information or unauthorized targets.
